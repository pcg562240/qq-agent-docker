正在读取当前机器人…

范围：当前机器人的配置、人设、聊天、文件记忆、已安装技能及专属 MongoDB 知识／记忆库。不覆盖其他机器人、共享模型服务、控制台密码或 Docker 环境。

备份含 QQ 凭据、技能密钥和聊天隐私，下载文件不加密，请妥善保管，不要发到群里或公开仓库。

导出／恢复会短暂重启机器人并暂停服务，以取得一致数据；正在回复时会拒绝操作，稍后重试。数据库不可达会停止操作，不生成缺库的“完整备份”。上限：压缩 512 MiB、解压 2 GiB、单文件 64 MiB、5 万条记录；更大的实例需离线管理员备份。

导入与恢复

只允许恢复到相同 AppID。先上传校验和预览，再二次确认。恢复前自动生成回退备份；MongoDB 使用当前实例的连接参数，不使用导入文件提供的数据库地址。

技能含可执行代码，仅导入自己或可信来源的备份。导入会替换当前机器人的数据，不是合并聊天记录。共享模型在另一实例上需单独配置。
