## 2. 五步

### 第 1 步：建仓库

建议 **private**（下面第 2 步会说明为什么）。

```bash
cd F:/kmy/Documents/dpsk/harness/qqa-linux
git init -b main
```

### 第 2 步：★ 隐私自查（**别跳过这一步**）

CI 需要 `ci-input/app-code.tar.gz` 才能组装。这个文件是**已套用隐私排除清单**的应用代码，
不是原始的 `resources/app`。先自己确认一遍：

```bash
# 解包到临时目录
mkdir -p /tmp/chk && tar -xzf ci-input/app-code.tar.gz -C /tmp/chk
# 用工程自带的复检（就是 CI 里跑的那一条）
bash scripts/99-selfcheck.sh --input /tmp/chk     # 期望：红线复检通过
```

**已经核对过的事实**（2026-09-28）：411 个条目，无 `.db` / `.log` /
`snowluma/config` / `community.key`，无 `sk-` 形式密钥字面量。

> ⚠️ **绝对不要提交原始的 `E:\Program Files\QQ Agent\...\resources\app`**。
> 那棵树里混着 QQ 登录态（`snowluma_identity.db`）、私聊消息库（`messages.db`，71 MB）、
> WebUI 令牌、以及 `data/config.json` 里的 API Key 明文。
> 见 `03-交接文档.md` §7 与 `05-arm64方案.md` §5.4。
>
> `.gitignore` 默认**忽略 `ci-input/`**。要提交它，得先完成上面的自查，再：
> ```bash
> git add -f ci-input/app-code.tar.gz
> ```

### 第 3 步：提交并推送

```bash
git add -A
git status --short          # 看一眼都提交了什么
git commit -m "QQ-Agent Linux 打包工程（含 arm64 支持）"
git remote add origin <你的私有仓库地址>
git push -u origin main
```

### 第 4 步：私有仓库要启用 Arm64 runner

GitHub 仓库 → Settings → Actions → Runners，确认 Arm64（`ubuntu-24.04-arm`）可用。
**公开仓库开箱即用**；私有仓库按 GitHub 的计费规则扣分钟。

### 第 5 步：触发

仓库 → Actions → `build-linux-arm64` → **Run workflow**。

> **不需要设任何 secret**：arm64 的 SnowLuma SHA256 已经核对并 pin 进 `scripts/lib.sh`，
> 构建会自己校验。留了个 `SNOWLUMA_SHA256_ARM64` 只是万一需要临时覆盖时的入口。

## 3. 跑完看什么

CI 会依次做（17 步，任一步失败即红）：

```
检出 → 确认是 aarch64 runner → 装工具链 → 检查 ci-input
  → ★ 隐私第二道闸门（99-selfcheck --input，不干净直接红）
  → 解包 arm64 运行时（含官方 SHA256 校验）
  → 组装 → ★ 架构审计（ELF/PE/权限）
  → 打 deb + rpm + AppImage
  → 产物架构静态校验
  → ★ 冒烟：deb（真实安装）
  → ★ 冒烟：rpm（真实安装）
  → ★ rpm 依赖解析验证（对照 Fedora/RHEL 真实元数据，用 dnf）
  → ★ 冒烟：AppImage（直接运行）
  → 上传安装包 + 三份测试报告
```

**要收集的东西**：

1. **三个 arm64 安装包**（`.deb` / `.rpm` / `.AppImage`）
2. **三份冒烟报告**（`report-smoke-arm64-{deb,rpm,appimage}.md`）
   —— 这三份是「arm64 真机验证」的**唯一**证据来源

**判读提示**：

- rpm 冒烟会出现「依赖未被真实验证」的警告 —— 那是**如实标注**：
  Ubuntu runner 上没有 rpm 依赖库，脚本回退 `rpm -i --nodeps`。
  **依赖要真验，得在 RHEL/Rocky/Alma/Fedora 上跑**（本机的 `qqagent-fedora` WSL
  实例 VHDX 丢失，至今没验过）。
- 如果 AppImage 冒烟报了沙箱降级提示，那是**预期行为**（见 `06-构建与验证实录.md` §4.7）。
